A simple and responsive e-commerce website built with Next.js and React. This project was created as a learning experience to practice component-based development, reusable UI components, and deployment with GitHub Pages.

## ✨ Features

- Responsive e-commerce user interface
- Reusable React components
- Product cards and product sliders
- Product images and promotional banners
- Component-based architecture

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ava-esmaeillli/nextjs-mini-projects.git
   ```

2. Navigate to the project directory:

   ```bash
   cd nextjs-mini-projects/nextjs-first-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build

To create a production build, run:

```bash
npm run build
```

The project uses Next.js static export to generate files that can be hosted on GitHub Pages.

## 🚀 Deployment

The website is deployed on GitHub Pages using GitHub Actions. The workflow automatically builds and publishes the project when changes are pushed to the configured branch.
